## 已确定的 14 项产品决策

| 编号 | 维护者决定 | 落地解释 |
| --- | --- | --- |
| D01 | RN，按建议的技术栈 | TypeScript + Kotlin / Swift 原生模块，新架构与 Codegen |
| D02 | 两端同时发布，只有普通版，iOS 先运行起来 | 同阶段交付 Android APK 与 iOS Simulator 应用；不要求先做 TestFlight / 上架；只用公开、正常用途的系统能力 |
| D03 | Android 15、iOS 18，仅手机 | 按最低版本和首轮验证基线配置；不承担平板或低版本兼容 |
| D04 | 多文件、纯文本 | 不做目录、剪贴板图片、富文本；图片 / 视频作为普通文件不受此排除 |
| D05 | 只做 LAN | 不做 APNs、账号、云端存储或跨网中继 |
| D06 | 无配对，只看频段 | 对讲机语义；不增加短码、扫码认证或可信设备列表。文件沿用单次接收确认 |
| D07 | 文件选目标，剪贴板同频段群发 | 文本向当前可达的同频段设备分发；无默认单设备限制和离线补发 |
| D08 | 可以要求升级桌面 | 桌面实现移动所需协议；旧桌面在移动端提示升级 |
| D09 | 不做特权增强 | 不实现 Shizuku、root、LSPosed；不保留它们作为首版验收条件 |
| D10 | 系统入口先做通知与 Widget | 不做接收外部分享扩展、用户快捷指令动作或磁贴；App 内选择和出站文件导出正常保留 |
| D11 | CakeUI 基础子集 | 约 10 个实际需要的原生基础组件，共享 AnyDrop 设计变量 |
| D12 | App 数据目录优先，完整导出，媒体进相册，不自动删除，无历史保留概念 | 已接收原文件持久保存；相册失败保留原件；不做剪贴板历史库、保留天数或到期清理 |
| D13 | Android APK，iOS 只需 Simulator | 不要求商店账号、TestFlight、iPhone 签名或发布材料 |
| D14 | 纯个人业余项目，无这些资源 | 不设团队、工期、专用设备要求；工具链按本机可用环境建立 |

两处实现解释：D06 不取消逐次文件接受，也不新增配对；D12 的“不自动删除”约束已接收内容，不把未完成临时片段变成永久历史。删除完成文件只能来自用户明确操作。

## 运行验证：不再以真机资源为前置条件

“环境内验证”要求在可用 Android 模拟环境 / iOS Simulator 中实际运行并记录结果；真实锁屏、省电、系统回收与 ROM 结论不能由模拟器结果替代，但缺少真机不阻塞本次交付。

| 编号 | 状态 | 当前验证目标 |
| --- | --- | --- |
| V01 | 环境内验证 | 无配对的 LAN HTTP 拉取、地址解析、频段检查和范围明确的网络配置；原配对证书 / HTTPS 真机门槛移除 |
| V02 | 环境内验证；真机行为后补 | iOS background URLSession 创建、任务映射、文件落盘和重新挂载；区分系统回收与强退，不声称 Simulator 已证明真实后台可靠性 |
| V03 | 环境内验证 | 多文件任务由原生安排，UI / JS 不在前台时不依赖逐个 JS 回调启动下一任务；不做目录解包 |
| V04 | 环境内验证；OEM 验证后补 | Android 15 FGS、通知、取消 / 恢复；模拟结果不外推成所有手机省电模式下可用 |
| V05 | 环境内验证 | JS 重建后读原生快照，进度和完成状态可恢复，文件不经过 JS base64 |
| V06 | 环境内验证 | 桌面与模拟设备互发现 / 直连、权限拒绝、地址选择；说明宿主网络与模拟器拓扑差异 |
| V07 | 环境内验证 | 普通权限的前台读、后台写尝试和通知打开前台复制；删除全部特权能力探测 |
| V08 | 环境内验证 | CakeUI 原生组件、Metro 消费、浅深主题、键盘、字体；Web 既有回归不退化 |

剩余问题主要是：局域网拉取协议与地址配置、频段变化时在途任务处理、多文件恢复、通知 / Widget 生命周期、相册权限与批量导出、RN / CakeUI 包结构及本机工具链。它们由实现和运行结果决定，无需重新提交 D01–D14 问卷。

没有新的外部项目文档必须由维护者提供；不再要求旧项目、Figma、配对密钥、云端域名、APNs、商店账号、专用测试设备或人员排期。后续遇到实际缺失的项目资料再单独列明。

下一步工程顺序：两端可运行骨架 → 桌面互通与纯文本群发 → 多文件 / 原生生命周期 → 通知 / Widget / 导出 / 相册 → 同阶段交付。iOS 真机行为将来可以补测，不阻塞当前 Simulator 目标。

本次只更新范围和实施清单，未创建移动端工程或执行发布。
